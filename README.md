📜 Estudo de Caso: A Ascensão da Ciência de Dados
Este repositório documenta uma jornada de aprendizado sobre as origens, marcos históricos e a consolidação da Ciência de Dados como disciplina independente. O projeto utiliza o NotebookLM como motor de síntese e curadoria de conhecimento.

🔗 Acesse o Caderno Temático: https://notebooklm.google.com/notebook/4573a513-e936-4d17-9847-0208315802f6

🎯 Contexto e Objetivos
O foco deste estudo é entender como a estatística clássica evoluiu para a Ciência de Dados moderna sob a pressão do Big Data e do aumento do poder computacional.
Exploração Histórica: Mapear a transição da análise de dados teórica para a aplicada.
Domínio de Ferramentas: Utilizar IA para curadoria de fontes complexas.
Construção de Repertório: Consolidar fundamentos que sustentam as tecnologias de IA atuais.

📚 Curadoria de Fontes
Para garantir a fundamentação teórica, o caderno foi alimentado com as seguintes fontes de referência:
📄 "50 Years of Data Science" (David Donoho): A evolução da disciplina sob a ótica de John Tukey.
🌐 "The Fourth Paradigm" (Microsoft Research): A ciência orientada intensivamente a dados.
📊 Relatórios de Mercado (McKinsey/Gartner): Panorama sobre o impacto econômico e o surgimento do "Cientista de Dados".
🎓 Papers Acadêmicos: Registros históricos de Peter Naur (1960) e Jeff Wu (1997).

📖 Miniguia de Estudo
1. Resumo Estruturado
A Ciência de Dados é o ponto de convergência entre:
Anos 60/70: O foco muda da matemática abstrata para a Análise Exploratória (EDA).
Anos 90: A necessidade de lidar com o armazenamento em massa.
Anos 2000: A oficialização da disciplina como união entre estatística e computação.

2. Glossário Chave
EDA (Exploratory Data Analysis): Investigação inicial de dados para descobrir padrões e anomalias.
Big Data: O volume, velocidade e variedade de dados que superam sistemas tradicionais.
Machine Learning: A capacidade de aprender através de dados sem programação explícita.
